### Game of Life ###
Basically implemented [this](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life) in python using OOP, and visualised using PyGame. I store the info (alive or dead/ black or white) in a nxn array, copy its content into a new array, loop over the main array and make changes to the new array. PyGame takes this info and just displays the colour.
